## WizardKit

WizardKit is a TypeScript library that lets your AI agent build a step-by-step wizard as a Deno script, 
served as HTML so the same script runs in a browser or a desktop window. I used it to create [split-utils](https://github.com/xyzshantaram/dotfiles-ai/tree/main/skills/split-utils), a tool to fetch and upload my e-commerce orders with my housemates to Splitwise, that works both for humans and autonomous agents.

Inspired by [wizard](https://github.com/mattpocock/skills/blob/main/skills/engineering/wizard/SKILL.md) by Matt Pocock.
